# Python Mini Projects

Five terminal programs that run with Python's standard library. From this directory, run a project with `python <script-name>.py`.

| Project | Script | What it does |
| --- | --- | --- |
| Simple Calculator | [`calculator.py`](calculator.py) | Four arithmetic operations with numeric input validation. |
| Number Guessing Game | [`number_guessing_game.py`](number_guessing_game.py) | Guess a number from 1 to 100 in up to ten tries, with higher/lower hints and scoring. |
| Rock Paper Scissors | [`rock_paper_scissors.py`](rock_paper_scissors.py) | Play five rounds against the computer and see the running and final scores. |
| Password Generator | [`password_generator.py`](password_generator.py) | Choose a length and character sets, then see the generated password and its estimated strength. |
| To-Do List Manager | [`todo_list.py`](todo_list.py) | Add, complete and delete tasks, clear completed items and save changes to `todos.json`. |

The To-Do List Manager saves `todos.json` in the working directory. The Password Generator uses Python's `random` module to demonstrate character selection.

See the [main README](../README.md#beginner-projects) for terminal previews.
